速览这份地图是什么

本项目为论文主工程提供文献追踪服务：围绕「人-机-料-法-环-测六源异构证据流 × 组合前治理」主线，按 G1–G8 八个方向持续扫描前沿。关键问题是——同一物理事件经多视图、多模型、多版本重复进入融合时，如何在组合前阻断未裁决依赖，并在版本 / 合并 / 退休 / 重放的全生命周期中保持根级贡献守恒；方法内核是 D-S/TBM 之上的 fusion-specific exactly-once 准入语义。

① 聚合空档被 2026 理论硬化，但竞争协议升级（池化后验）；
②「大模型只能是受控证据源」获三向独立证据；
③ 拒判统计可证书化，no-harm 不必自造。

跨向跨方向发现（对研究方向的核心判断）

G3 → 论证 聚合空档被 2026 理论硬化，但竞争协议升级。 Blackwell 结果 [papers/p10@3] 证明投票与辩论诱导的信息结构不优于全体私有信息的池化；论文中「替代辩论/投票」的叙事应从「空档存在」升级为「证据论协议提供投票所不具备的无知表示、冲突度量、依赖路由与拒判语义，且与池化后验可对撞」。MME 第五臂建议加入 product-of-posteriors 型基线。
G6 + G2 + G3 → 设计 「大模型只能是受控证据源」获三向独立证据。 LLM-HAZOP 场景仅 19–37% 技术有效 [papers/p32@1]、生产环境记忆投毒实测 [papers/p14@1]、EDL 单趟校准路线成熟 [papers/p05@3][papers/p07@1]——可靠性权重 + 复核门禁 + 校准外挂不是保守设计，而是必要配置；可在论文引言引为设计动机。
G8 → 方法 拒判统计可证书化，no-harm 不必自造。 SCoRE / joint certificate [papers/p38@3][papers/p40@3] 的「风险上界 + 接受下界 + 效用下界」三重证书与可用性判据直接对应 C2′ 的报告格式；建议 v21 §6.3 引用并采用其证书结构，把「拒绝不伪装安全」从设计原则升级为可检验统计陈述。
G2 → 邻近警示 LLM 证据治理同步兴起（本轮唯一需主动防守的邻近面）。 BELIEFRAG [papers/p52@1] 的「证据状态」闭环与系统级不确定性传播分类 [papers/p55@1] 说明「证据生命周期治理」在 LLM 侧成为热点；本文须在引言明确对象差异（BF 组合前准入 / 根级守恒 vs RAG 控制回路状态），避免被读作重叠。

G1依赖证据 / 冲突新作 月度

最新进展

  • 混沌冲突度量 + 历史经验加权（arXiv:2608.13108，2026-08）[papers/p01@1]：把「证据间冲突」与「证据内非特异性」联合度量（五条形式化性质），用谱聚类划分决策空间、遗憾理论计算历史可靠性画像；16 个基准平均 F1 85.78 / AUC 93.30，超 8 个 DST 基线。
  • 复杂网络可靠性模型（Tang et al., Group Decision and Negotiation 35(3), 2026）[papers/p02@1]：把证据体当网络节点、证据距离当边权，用直接/间接强度定权，缓解高冲突反直觉。
  • 软似然 + 可靠性优化（Lu & Zhu, EAAI 163, 2026-05）[papers/p03@1]：SLSQP 约束优化估源相似度 + OWA 权重替代差分权重，单步软似然融合；目标识别 +0.14pp。
  • 中文期刊动向（兵器装备工程学报 2026 增刊）[papers/p04@1]：模糊隶属度→全集未知分配 + 内聚度/冲突度双维加权——「BPA 未知项的物理意义」仍是活跃问题。
  • 领域 SLR 锚点（Fei, Li & Ding, Neurocomputing 643:130419, 2025）[papers/p30@1]：DST × 安全/事故/应急的系统综述，按 4R 危机管理框架分类——「安全 × 证据理论」是窄口而非空白，差异化必须在治理/依赖/生命周期维度上主张。
  • 量子干涉再分配（IEECR, SSRN 7549569, 2026）[papers/p44@1]：焦点元素关联图量化命题间干涉强度，将多元素焦元质量再分配至单点；模糊隶属度生成 BPA + Deng 熵排序证据；四数据集超 5 个代表性融合方法（91.00% / 85.00%）。
  • 依赖感知风险界（gamma-CUBV, arXiv:2610.03465, 2026-10）[papers/p45@1]：折间等相关下有效折数 Keff=K/[1+(K−1)ρ]，按「未来风险上界最小化」选权——依赖折扣首次以风险证书语言出现在分析侧（与 G3 的 Neff 同构；本文主张治理侧，不与之争新颖）。
  • Information Fusion 125（2026）目录信号[papers/p46@1][papers/p47@1]：过自信/非合作行为的多尺度群决策融合（103401）、概率密度的边际分布鲁棒融合（103423）——顶刊入口在「行为偏差 × 鲁棒融合」。
  • IJAR 认知不确定性应用（2026）[papers/p48@1]：元公平框架下 DST（Yager 函数 + 厚区间）医疗风险预测，含 50 人用户研究（经中文新闻转述，引用前核原文）。

现存瓶颈

单次组合规则拥挤且增量收窄；依赖仍以「估计参数」或「内容相似度」为主，没有把依赖当前置的资格路由；绝大多数不评估流式/累计影响。本轮增量出现依赖折扣的分析侧证书化（p45）与冲突再分配的量子化新形态（p44），但组合前资格、exactly-once 与生命周期治理仍无对应工作——本文差异化空间未被压缩。

G2EDL×LLM 校准 月度 防守面

最新进展

  • 证据知识蒸馏（arXiv:2507.18366，2025-07）[papers/p05@3]：把需多趟采样的不确定性教师（BNN / Laplace / BayesPE）蒸成 LoRA 学生、单趟输出；softmax 与 Dirichlet（evidential）两条学生路线，后者显式建模认知不确定性；代码开源（BPE-KD）。
  • DRO + 证据集成校准微调基础模型（ICLR 2026）[papers/p06@1]：微调后验变平坦/多峰导致 UQ 失效，用分布鲁棒优化 + 证据理论做多样性集成，理论保证校准改进；覆盖大视觉语言模型。
  • Evidential Transformation Networks（ETN, 2026）[papers/p07@1]：post-hoc 轻量模块，在 logit 空间学样本相关仿射变换→Dirichlet 参数，让现成预训练模型输出 EDL 式不确定性，单趟免重训——为「给 VLM 证据源外挂校准器」提供现成路线（source_only：经二手技术媒体转述，引用前定位原文）。
  • EvidentialRAG（2026-07）[papers/p08@1]：用 EDL 量化并缓解多源 RAG 的信息冲突——直接对应语义证据的冲突处理（source_only：经论文聚合站转述）。
  • post-hoc 冲突感知校准成形：C-EDL（arXiv:2506.05937 v3 2026-10-02 = ICLR 2026 正式版）[papers/p49@1] 与 CLEAR（arXiv:2610.01384）[papers/p50@1] 以「任务保持变换 / 潜空间扰动视图」量化表示分歧，动态压低证据强度；C-EDL 把 OOD/对抗覆盖降至约 55% / 90%，CLEAR 提升 OOD/对抗 AUROC +8.29 / +5.01 且比同类 post-hoc 快 17.4×。
  • 证据蒸馏「支持 vs 质量」分离（EESD, arXiv:2610.08514, 2026-10-06）[papers/p51@1]：执行相关性（支持）与有效伪计数（证据量）分开建模，Dirichlet 后验产生不确定性惩罚权重；NLL 降 55.0–59.3%，一轮修正学习后 Pass@1 15.0→20.4%（[+2.8, +8.0]pp）——与「贡献守恒 / 质量元层」同向的 LLM 侧旁证。
  • RAG 证据状态治理登场（BELIEFRAG, arXiv:2609.39139）[papers/p52@1]：显式状态（充分性/可靠性/冲突/不确定性/缺口/获取成本）闭环控制检索—改写—验证—回答—停止—拒答；F1 0.572 vs 0.555 且 token 省 39%；「校准的可回答性」最有效，但来源漂移可使同一决策信号失效——LLM 证据治理最邻近工作，须引用并定位差异。
  • conformal 校准外挂成熟：SLLCP（冻结 VLM + 标签局部化 conformal，肇事轨迹识别 89.6% / 88.4% vs 基线 4.6% / 39.1%）[papers/p53@1]；paraphrase-aware conformal（改写鲁棒，NeurIPS 2026）[papers/p54@1]。
  • 系统级不确定性传播（arXiv:2604.23505，雪球发现）[papers/p55@1]：不确定性在复合 LLM 系统内跨边界被变换复用，早期错误传播复合、难检测难治理；给出 P1/P2/P3 分类与五个开放挑战——与「生命周期一致治理」问题意识直接同构，可引为问题动机。
  • 资源盘点：awesome-evidential-deep-learning 经 raw README 核实（48KB）——列表最后更新 2025/01，已停更，2026 年 G2 追踪不能依赖它；列表确认含 4 篇综述（2022 belief theory meets DL、2022 IJCAI evidential reasoning survey、2023 TMLR prior/posterior networks、2024 综合 EDL survey）[papers/p09@1] 与 IB-EDL（ICLR 2025，openreview PDF + 代码库）[papers/p43@1]；另存 BFTA 2025 Denœux 讲义（Evidential ML 全集）。

G3多智能体聚合与记忆治理 季度 竞争协议升级

最新进展

  • Blackwell 信息量视角的形式化判决（arXiv:2605.06028，2026-05）[papers/p10@3]：证明投票与辩论诱导的信息结构不优于全体私有信息的池化，贝叶斯池化后验是 Blackwell 序下的上界；MA-PoP（product-of-posteriors）在 6 个 QA 基准超过 SOTA 辩论 / 投票且 token 更少。既是「辩论/投票无原理性」论证的 2026 最强外部佐证，也引入了强竞争协议——MME 基线必须认真考虑。

现存瓶颈

池化后验强的协议假设条件独立；证据论路线缺少与 Blackwell / MA-PoP 同量级的信息量层面对比；记忆防御（A-MemGuard 等）与融合层的耦合尚无标准评测。

后续关注重点

Blackwell / 池化后验与证据聚合的对比实验（可作 MME 第五臂）；记忆投毒与 lineage 交叉的评测基准；NIST AI Agent Standards Initiative（2026-02）后续文件。

来源与时间范围：WebSearch 2026-10-08；覆盖 bounded。secondary 来源（博客 / 新闻）仅作线索，引用前须回原文。

G4provenance × BF 季度

最新进展

  • PRIMEX-PEV 正式出版（J. Advances in Information Fusion 20(2):152–171, 2025-12；Chang, Kuo, Bar-Shalom, Chong, Mori）[papers/p16@1]：素指数向量（PEV）表示，在指数空间用 GCD / LCM 做冗余消除与谱系保留；扩展异步更新与部分信息传播；面向边缘 / 联邦 / 资源受限。最接近的 lineage-only 强基线有了权威最新版。

G7本体栈与数据质量 半年度

  • 语义图统一工业数字主线（arXiv:2608.24918, 2026-08）[papers/p35@3]：本体驱动 RDF 知识图谱统一 11 类系统（ERP / MES / PLM / SCADA / QMS / SCM），78 类 / 108 对象属性 / 243 数据属性，援引 ISA-95 / OPC UA / eClass / AAS / RAMI 4.0；实证：阻断 24 个跨系统工具后 recall 1.00→0.31，69% 可发现信号需跨系统连接；经 287 个 MCP 工具暴露给 LLM 智能体。

G8前兆挖掘与选择性预测 / IUT 半年度

最新进展

  • 选择性预测证书化：SCoRE（arXiv:2603.24704, 2026-03）[papers/p38@3]——广义 e 值 + 假设检验，对任意有界连续风险给出有限样本信任决策，免均匀集中、可推广到分布漂移；临床分流（Sci Rep 2026, Kwon & Kim）[papers/p39@1]——split / Mondrian / 加权 conformal + 成本感知延迟，80% 覆盖率下保留案例错误降 46.7–49.6%；joint finite-sample certificate（arXiv:2606.08517）[papers/p40@3]——单证书同时上界被选风险、下界接受概率（1/√p_min 改进 vs 1/p_min）与下界部署效用。与「拒判成本 / 可用性 no-harm」同构，可直接采用而非自造统计工具。
  • 前兆挖掘 / 领先指标：预测性安全分析（near-miss 聚簇、纠正措施逾期、班次压力等领先指标）成为 2026 EHS 软件主线；CanQualify 2026 框架称领先指标 + 预测模型比滞后指标准 25–40%、案例称 TRIR 降 20–40%（厂商研究 / 案例，证据弱，须标注）[papers/p41@1]；业内共识：需 2–3 年一致数据，最大障碍是数据纪律而非算法 [papers/p42@1]。
  • IUT / 共同主终点：本轮未检索到 2026 新综述；项目内 v6.8 已采用（交并检验、SESOI、no-harm 门、联合功效 Monte Carlo、预算硬门）——保持项目内权威，外部只需追踪统计社区对 adaptive selection 下证书的新结果（p40 即相关）。
