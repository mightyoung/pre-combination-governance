# 论文库梳理汇总（2026-10-08）

> 对象：本目录内全部论文稿件、开题文档、投稿配套件与实验设计文档。

## 1. 总体定位

- **业务领域**：工业安全，具体经历三次聚焦——① 泛工业系统整体安全（人、机、料、法、环五维实时风险评估）→ ② 工业人机协作（HRC）安全 → ③ **动态生产过程安全**（危险—屏障、独立保护层、工艺偏离升级），以放热 CSTR 超温—超压仿真为确认性主域、TEP 为迁移压力域。
- **学科方向**：多源信息融合（Information Fusion）与不确定性推理，核心数学工具是 Dempster–Shafer 证据理论 / 可转移信念模型（TBM）。
- **最终投稿目标**：Elsevier《Information Fusion》（配套件 Title-Page / Highlights / Cover-Letter 均针对该刊）。
- **当前机器权威状态**（`GateChecklist-v6.13.json`）：`FORMAL_EXPERIMENT_BLOCKED`；正式准入文件 `FORMAL_STAGE_ADMISSION-v6.13.json` 不存在，确认性实验被阻塞；工程资格证据（runtime 回归、数据集完整性）不得写成论文性能结论。

## 4. 各论文（版本）之间的关联与差异

**关联（同一条主线的五次重心迁移）**：

```
初稿(五流分层融合/分类性能)
  → VLM-LLM重构(v3–v8): 大模型受控证据源 + 多智能体 + 连续趋势 + 双重/三重保证
  → v10–v13: 两层表示修正D-S语义错误 + 来源感知 + 闭式Lipschitz界
  → v14–v19: 认证主体/预算/锐界 + 过程安全主域 + 安全工件编译 + 规格冻结
  → v20–v22: 组合前治理 + fusion-specific exactly-once + 生命周期一致性
```

贯穿始终的不变内核：**D-S 证据理论为协调协议 + "人机料法环"作为证据来源分类 + 对不可靠/同源证据的显式治理 + 可审计可回放**。变化的是问题定义与理论贡献形式。

**差异（版本间对比维度）**：

| 维度 | 初稿/v3–v8 | v10–v13 | v14–v19 | v20–v22（当前主线） |
|---|---|---|---|---|
| 核心问题 | 如何融合五流并分类/连续评估 | 同源重复增信、累计影响、高冲突 | 依赖不可验证时如何限权与失败关闭 | 提交后生命周期如何原子重建认知贡献 |
