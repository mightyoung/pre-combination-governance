## 设备模型输出候选契约

- 设备/目标部件/工况标识、健康命题、输出单位和语义：异常分数、状态标签、故障候选或不确定度需分别说明，不能直接当事故概率。
- 模型ID、版本及适用工况、基线版本、训练/校准数据来源和截止时间；分布外或基线不适用时保留缺口，不自动降风险。
- 源测量时段、输出生成时间、接收/入库可知时间、质量及有效性；时间长期不变不直接等于失效，事后模型重算不得倒灌早期前缀。
- 依赖的传感器/采集实例/片段/派生链、共享基础模型和共享预处理；模型结果与其原始传感器输入不是两份独立证据，不将多个派生模型数量等同来源数量。
- 原证据引用、可追溯推断依据、纠正/撤回/复核状态；模型输出作为一条带血缘证据，故障归因和事件同一性由相应任务另判，不能直接由分数代替。

DS接线应先对齐命题、时间及来源依赖。若模型与输入传感器共享同采集，应采用明确共同依赖处理或保留相关性未知，不直接独立组合。血缘去重也不等于丢弃原输入；原数据和派生解释可保留，风险贡献与呈现用途分开。设备健康异常不自动证明某人员进入事件更危险，需当前目标、工况和危险证据关系。

## 台账接口候选契约

数据库事件/整改/真假复核/纠正台账为事实源；结构化事件卡及历史摘要引用记录ID、来源版本和重建截止时间。候选查询条件包括资产/隐患目标、设备工况与业务关系版本、physical event time以及available/recorded-at time双截止。不能仅筛事件发生时间后读取后来补录的整改结论。

每条历史风险保留真假复核、未闭环/已闭环/未知状态及其证据，历史次数不自动升级物理风险。未闭环复发可提高核查优先级；危险等级上调需当前证据或持续暴露依据。已证伪历史、旧模型推断及其摘要不能循环当作新增独立支持。

结构化历史摘要作为可重建查询加速，不覆盖台账事实；不先搭独立LLM长期记忆。未来只有字段查询遗漏自由文本信息或实测查询慢时再评估语义检索/缓存，并比较相同可知信息下的判定、错误与成本。当前不接数据库、不建向量库、不调用模型。
