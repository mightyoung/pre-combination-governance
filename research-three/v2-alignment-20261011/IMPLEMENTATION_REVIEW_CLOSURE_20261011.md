## 后续复核：同刻值的类型敏感等价

独立复核指出 Python 的 `==` 会把 `True`/`1`、`1`/`1.0` 以及嵌套 tuple 中的对应值视为相等。独立复现中，反转同刻重复事实顺序会选出不同 Python 值类型，造成序列化结果和哈希变化。新增回归测试先以六种类型/顺序组合失败。

修订后的重复值等价契约要求递归结构中每层 Python 类型完全一致、值相等，且 producer 与 evidence refs 一致。`True` 与 `1`、整数与浮点数、嵌套 tuple 中的类型差异均视为同刻冲突并失败关闭；实现不把 int/float 归一化为同值。修复后前缀适配器与身份转移相关的 14 项 focused unittest 通过，覆盖此前 13 项和新增类型敏感回归用例。评分分母、真值匹配仍为草案，本次没有扩大实验。
