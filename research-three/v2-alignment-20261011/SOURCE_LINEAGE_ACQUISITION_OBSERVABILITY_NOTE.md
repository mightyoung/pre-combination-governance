# 来源谱系的最小可观测方案

- **状态：** 短设计，等待 parent 选择可用观测源；没有生成夹具、运行合同或扩大实验。
- **边界：** 方法输入只含实际可采集的来源与处理记录。隐藏 `source_family`、episode 真值或 scorer 标签不作为观测。

## 从原始采集到派生算法

| 阶段 | 候选采集字段 | 可核验范围 | 只能声明的部分 |
|---|---|---|---|
| 原始采集 | 连接器/collector ID、来源端点、来源原生 record/event ID、原始 payload 引用或哈希、来源时间及原始时区、接收时间、请求/响应或订阅游标 | 本地首次接收时间、保存字节的摘要、可验证签名/证书；签名只证明签发者与字节完整性 | 来源 ID 的语义、来源时钟是否正确、事件 ID 是否唯一代表一个真实事件 |
| 转发/队列 | parent record/hash、转发 envelope ID、sender/receiver、topic-partition-offset 或等价游标、发送/接收时间、重试/重放 ID | 若保留两端日志，可用 parent/child 哈希、偏移连续性及签名日志核对一段具体转发 | 只给出 lineage edge、trace ID 或“完整”标记而无两端收据时，转发关系与完整性仍是声明 |
| 派生处理 | transform 名称/版本、代码或容器摘要、配置摘要、输入引用/哈希、输出哈希、run ID、执行时间、可复现算法的随机种子 | 保存输入、代码、配置后可重放并核对输出；受信任的追加式执行收据可证明某个运行记录 | 仅有算法版本字符串或输出哈希不能证明历史上确实运行了该算法 |

每个节点/边应带 `actual_available_at`、`earliest_known_at`、`source_ref` 和 trust 状态。由本地接收器打出的时间与哈希可核本地记录；供应方时间、节点语义和 trust 等级需要来源签名、独立日志或明确标为声明。`trace_complete=true` 只有在有限窗口内有完整导出、游标/偏移无缺口且可与接收记录对账时才可升级为已核验；否则保留 `UNKNOWN`。相同来源标签或不同 root ID 都不证明独立性。

## 最小可辨识开发样例

选定一个能导出原始记录和逐跳日志的来源后，先收集以下四类**成对记录**。事件关系真值须来自原生签名 event ID、可追溯的原始公告/文档链接，或独立人工裁定；只把裁定及其证据引用放在输出冻结后读取的 scorer sidecar。若没有足够依据，标 `NOT_SCORED_UNIDENTIFIABLE`。

采集 `record_id` 和 parent/child 引用是重建谱系的普通可见输入。原生 `event_id` 只有在目标系统本来就向方法暴露时才进入方法输入；若它只用于独立裁定，则仅存于 scorer sidecar。无论哪种情况，都不把 `SAME`/`DIFFERENT` 标签或隐藏 family 字段交给方法。

1. **同一事件、共享已核验上游：** 同一原生 event ID/原始 payload 被两条采集或转发路径接收；用 parent hash 和收据证明共享上游。
2. **不同事件、共享已核验上游：** 同一 feed 中两个不同原生 event ID 和不同 payload；两条记录仍有可核验共同来源。该例用于区分“共享来源”和“同一事件”。
3. **同一事件、未观察到共同上游：** 两个来源记录由原生事件 ID 或原始文档交叉引用确认同一事件，且各自有限窗口的来源日志完整、没有共同已知节点。结果只记 `NO_SHARED_KNOWN_ANCESTOR`，不能称统计独立。
4. **不同事件、未观察到共同上游：** 不同原生事件 ID/原始记录和不相交的完整观测链，作为边界对照。

四类样例都要提供来源原生 ID、接收时间、payload 哈希、可用的每跳 parent/child 收据、派生输入/输出哈希及时间、窗口完整性证据。声明的 root ID 可在每类内变化以检查方法是否只依赖字符串；同一可见图仅替换 root 字符串的克隆对只能测试敏感性，不能计为独立来源或事件准确率样本。事件关系标签与任何隐藏 family 字段均不进入方法输入。

## 等待 parent 选择的具体问题

- 哪一种来源/连接器能导出原始 payload 或稳定摘要、原生 event/record ID 和本地接收时间？
- 是否有转发两端或 broker 的 parent-child 收据、offset/cursor 和重放记录？可保留多长时间？
- 派生算法能否给出代码/容器与配置摘要，并保留精确输入、输出引用？
- 哪个有界时间窗或序号范围能证明日志完整；若无法证明，是否接受这些案例保留为 `UNKNOWN`？
- 同一事件关系由什么独立证据裁定：签名 event ID、原始文档链接，还是人工复核？没有该证据时应剔除哪些样例？

待 parent 选择具体观测源和可提供字段后，再冻结一组可审查输入。此方案不依赖私有旧 V2 规格，也不授权本轮提前运行新实验。
