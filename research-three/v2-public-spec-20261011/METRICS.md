# V2指标定义：结果驱动、探索性

旧严格首报评价与控制器失败记录保持原样；新指标单独报告，不能事后将旧失败改为新验收通过。此公开版仅定义指标，不包含原始输出、逐例映射或新实验结果。

| 指标 | 分母／定义 | 必需证据 |
|---|---|---|
| producer复核生成及时性 | 每个公开可识别风险/关联待核触发区间；首reason前缀－首次触发前缀 | 前缀、输入门控、reason记录 |
| 待核实风险提醒完整性 | 提醒对象的风险等级、依据、内容、身份/关联状态、卡链接字段齐全且不误称确证 | 序列化提醒payload与真实展示内容 |
| 用户可见提醒及时性 | emitted_at/visible_at－trigger_known_time；逻辑同prefix另报；丢失/超时分别统计 | 同时钟的检测、发送、展示回执及指定SLO |
| 事件确证精确率／误确认率 | 有确证决定的可核标签事件或关系；UNKNOWN不算正确确证 | 绑定观测/事件的决定、独立评价真值与来源 |
| 事件确证覆盖／延迟 | 可评价物理或脚本事件机会中确证数量及证据可用后延迟；缺证与可确证分层 | 边界证据可用时间、真值资格与决定日志 |
| 错误合并／错误拆分及待关联覆盖 | 明确SAME/DIFFERENT决定与真值比较；UNKNOWN比例、未解决时长另报 | 独立候选节点、关系状态、版本历史 |
| 显示卡持续与分拆可追溯性 | 展示层ID是否持续；候选节点是否保留；分拆与旧卡历史可追踪 | display_card_id、更新/分拆日志与展示记录 |
| 提醒负担 | 每触发区间首提醒、重复提醒、升级及确认更新分别计数；持续E1对照不能丢 | 事件状态、去重key、通知种类/级别 |
| 控制器资源/清理验收 | 相应运行scope的监测、回收、EOF、权限错误与未知项 | 实际运行receipt原样 |

分别报告每项PASS/FAIL/UNKNOWN或NOT_EVALUABLE、分母与缺失原因，不将提醒及时性和新事件确证准确性合并为总通过率。缺展示字段不能视为零延迟或成功发送；UNKNOWN与弃权不能从报告消失。确证精度须同时报告覆盖、弃权和隐藏事件机会。

作者脚本标签只支持脚本对照；真实物理正确性需要独立采集和标注证据。共享输入、规则或生成模板的记录不能当独立样本，不据此推断显著性。

本规格在查看旧结果后修订。未来实现须冻结新的规格、版本与评价器，以独立未见场景或预先保留数据验证；相同生成模板不足以证明真实外部有效性。禁止按用例ID硬编码卡身份、提醒等级或阈值，oracle只能用于评价。无新的执行许可。
